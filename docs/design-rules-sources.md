# 排布设计规则来源

这些资料用于确定候选偏好和软门槛，不把所有数字都当成住宅硬规范。

- [US Access Board：无障碍通道](https://www.access-board.gov/ada/guides/chapter-4-accessible-routes/)：连续净宽约 915mm，短距离最窄约 815mm。项目中作为无障碍模式参考；普通住宅紧凑模式可更小，但不能形成不可达口袋。
- [IKEA：沙发尺寸选择](https://www.ikea.com/es/en/rooms/living-room/how-to/how-to-choose-the-size-of-your-sofa-pub3e842ce0/)：沙发与茶几约留 45cm，并保留主要行走空间。
- [IKEA France：沙发布置距离](https://www.ikea.com/fr/fr/rooms/living-room/how-to/quelle-dimension-canape-choisir-pub98489f20/)：沙发周边约 60cm、沙发与茶几约 50cm，可作为舒适偏好带。
- [IKEA：L 型沙发布置](https://www.ikea.com/gb/en/rooms/living-room/how-to/how-to-arrange-an-l-shaped-sofa-in-the-living-room-pub7947efe0/)：L 型沙发可悬浮布置，贵妃位朝向电视，地毯用于把会客组连成整体。
- [IKEA：餐厅尺寸指南](https://www.ikea.com/sg/en/rooms/dining/dining-room-guide-pub21ad8080/)：餐桌到墙/柜约 80cm，到厨房操作台约 120cm，每位成人桌面宽度约 60cm。
- [IKEA：卧室收纳](https://www.ikea.com/us/en/rooms/bedroom/how-to/create-a-walk-in-wardrobe-in-your-bedroom-pub5f0c4000/)：收纳集中布置，并在柜门前保留真实使用空间。
- [Sony：电视尺寸与观看距离](https://electronics.sony.com/how-to-select-tv)：电视高度可用观看距离约三分之二估算，项目中用于电视柜—沙发距离的软偏好。

落地原则：常见距离进入偏好评分；门、柜门、碰撞和不可达区域进入硬检查；地面死角与墙面碎缝进入严重缺陷封顶。
