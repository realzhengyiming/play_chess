# 设计师俯视布局规律：卧室、客厅与融合单间

更新日期：2026-08-10

用途：把本项目收集的 7 张俯视参考图，转译成可用于家具配置、候选生成、局部落子分和终局全局分的设计规律。本文是长期参考，不等于已经全部实现。

## 先说结论

这些图共同表达的“丰富”不是家具越多越好，而是：

1. **沿墙形成连续、完整的功能带**，例如床组、书桌组、收纳墙、电视墙。
2. **家具按功能组合出现**，例如沙发＋茶几＋单椅，而不是孤立地摆一张椅子。
3. **中央留白必须有用途**：要么是主通道，要么是会客/阅读区，不能只是搜索没有摆到东西后剩下的大洞。
4. **真实家具承担空间构图，填缝件只修小缝**，不能靠长条定制柜冒充丰富。
5. **大房间优先使用大模数家具和更多完整功能组**，不是把小家具彼此拉远。

一句话概括：**丰满感 = 完整功能组 + 有层次的墙面 + 有明确用途的留白，不等于家具件数。**

## 证据边界

### 可以从图片确认

- 家具的大致类别、朝向、相互关系和功能分区。
- 哪些墙承担床、工作、收纳或视听功能。
- 中央空间是被会客组占用，还是被保留为通行带。
- 家具是孤立摆放，还是形成组合。

### 只能合理推测

- 图片中的空间可能是模型、渲染图或经过透视处理的场景。
- 有些床、柜和过道比例可能不符合真实住宅尺寸。
- 门的位置、开门方向和完整通路在部分图片中不可见。

### 不能从图片推导

- 精确到厘米的人体工学距离。
- 法规、安全通道和柜门开启净宽。
- 图片里的所有装饰品都适合进入硬家具排布。

因此：图片只用于提取**关系和构图偏好**；0.50m 最小通路、零孤岛、门扇和柜门使用区仍由项目硬规则决定。

- 中央休闲岛只有在四周仍保持连通时才加分，否则应被通行硬规则剪枝。

事实观察：

- 双人床、书桌椅、大衣柜、单椅圆几和一张小床/榻形成多个组。

### 图 6：卧室与客厅真正融合

来源：[img_v3_0214b_b148fe4e-e2d9-49b5-9eef-826786cb606g.jpg](../img_v3_0214b_b148fe4e-e2d9-49b5-9eef-826786cb606g.jpg)

事实观察：

- 床位于窗边上方；右侧是长沙发，左侧是电视/展示柜。
- 茶几位于沙发前方，单椅位于电视侧，形成有朝向的会客关系。
- 衣柜位于入口附近，中央家具密集但分组关系清楚。

可提取规则：

- 大卧室可以启用“酒店/套房会客组”：小沙发、茶几、电视柜应成套出现。
- 电视柜的优先级高于普通展示柜；沙发应正对或至少明显朝向电视。
- 单椅是会客围合的一部分，不应与主沙发方向无关。

### 图 7：小空间沿墙布置，中央保留完整活动面

事实观察：

- 床、休闲椅、衣柜、书桌和矮柜全部靠外围布置。
- 中央留白近似规则矩形，可连接床、桌、柜和入口。
- 高衣柜占无窗墙，书桌和床靠近采光面。

可提取规则：

- 小房间优先“沿墙压紧”，不要把家具均匀撒在房间里。
- 规则、连通的中央活动面可以保留；狭长死缝和角落孤岛必须重罚。
- 小房间的丰富度来自功能完整，而不是把中央通道填满。

## 重复出现、可信度较高的设计规律

### 1. 家具先组成“功能组”，再参与整屋排布

建议的基本组：

| 功能组 | 核心家具 | 可选补充 |
| --- | --- | --- |
| 睡眠组 | 床 | 床头柜、床尾凳 |
| 工作组 | 书桌＋工作椅 | 书柜、矮柜 |
| 卧室休闲组 | 休闲椅/小沙发＋小几 | 边几、落地灯 |
| 客厅会客组 | 主沙发＋茶几＋电视柜 | 单椅、边几 |
| 餐饮组 | 餐桌＋至少两把餐椅 | 餐边柜 |
| 收纳墙 | 衣柜/书柜/展示柜 | 小于成品宽度的收口件 |

启发：**完整的两件套比两个互不相关的小件更有价值。**

### 2. 墙面有主次层级

- 主墙由床、沙发、电视柜、长书桌、衣柜等核心家具承担。
- 次墙由书柜、餐边柜、展示柜等真实辅助家具承担。
- 填缝件只修安装缝和不足以放成品家具的小墙段。

启发：填缝件不得计入核心功能、丰富度或主墙完成度；填缝总宽度也不应压过真实柜体。

### 3. 中央留白应判断“用途”，不能只判断“大小”

可接受留白：

- 从入口连接床、衣柜、书桌、沙发的连续通道。
- 形状规则、四周可达的活动面。
- 会客组或阅读组的共享使用区。

应扣分留白：

- 家具围出的不可达孤岛。
- 宽度尴尬、无法通行也无法放家具的狭缝。
- 大块空地没有连接目标，也不属于任何功能区。

### 4. 家具贴边，但功能区朝向房间内部

- 床、衣柜、书桌、展示柜多沿墙布置。
- 椅子、茶几和床尾凳通过相对关系靠近主体。
- 家具实体可贴墙，使用区与柜门区必须留在可达空间内。

### 5. 自然采光影响家具类型和高度

- 书桌靠近窗边可加分。
- 高衣柜、书柜和展示柜遮挡窗时重罚。
- 窗下优先低矮书桌、矮柜或床，但床靠窗只可作为弱偏好，不能当硬规则。

### 6. 大空间通过功能组和家具模数增长

- 空间增大时，先尝试更大的桌、沙发、柜体模数。
- 模数升级后仍有有效空间，再加入休闲组、餐饮组或更多收纳组。
- 不应先选择小模数，再靠拉大家具间距制造“占满”的假象。

## 应如何进入系统

### 一、适合写入配置的偏好

| 规律 | 建议配置归属 | 说明 |
| --- | --- | --- |
| 房间启用哪些功能组 | `layoutConstraints.inventory.roomAreaModules` / 功能组配置 | 面积只是初筛，最终能否落下仍由几何搜索决定 |
| 每个面积/轮廓需要哪些真实沿墙家具 | `inventory.stagedSupport` | 矩形和多门异形房间应允许不同目标 |
| 家具相对位置和朝向 | `furnitureRules[].candidate.rules` | 如椅靠桌、茶几在沙发前、电视正对沙发 |
| 同类家具尺寸模数 | `geometry.variants`、`search.sizePolicies` | 大模数应在可行时优先 |
| 功能组最低完成数量 | `longBedroomChallenge.requiredCounts` 或通用 bundle minimum | 例如床尾凳、正式浅柜 |
| 填缝件地位 | `postLayout.wallComplements` | 只修小缝，不计丰富度 |
| 采光、高柜避窗 | 家具 placement / candidate 配置 | 属于设计偏好，不属于通行硬规则 |

原则：配置描述“想要什么”；引擎负责“如何采样、碰撞、算分和搜索”。

### 二、适合进入局部落子分

局部分负责判断“这一手是不是一个有希望的落点”，建议加入或加强：

1. **组合关系分**：椅靠桌、茶几靠沙发、床尾凳靠床尾、电视正对主沙发。
2. **墙段利用分**：真实柜体使用完整连续墙段加分；留下 0.08–0.70m 尴尬碎缝扣分。
3. **主次家具分**：核心家具和正式辅助家具优先；填缝件不参与 Beam。
4. **采光分**：书桌靠窗加分，高柜遮窗重罚。
5. **模数分**：同样合法时，大房间优先更大模数；不能只按家具件数排序。
6. **后继可行性分**：落下主体后，仍能放下其依赖家具和保留主通路时加分。

不建议加入局部分：整屋平衡、最大空地、所有墙面完成度。这些只有终局或较完整中间局面才看得准。

### 三、适合进入全局终局分

1. **功能组完整度**
   - 完整组高分；只有主体、缺少依赖家具时扣分。
   - 正式组的权重高于孤立小件数量。

2. **有效留白评分**
   - 奖励入口到主要家具之间连续、规则的通道。
   - 惩罚不连通空洞、死角和无功能归属的大块空地。

3. **墙面层级评分**
   - 检查主墙是否由核心家具承担。
   - 检查真实柜体覆盖率、最大连续空墙、角落碎缝。
   - 后补收口宽度不计入真实墙面完成度。

4. **功能区展开度**
   - 睡眠、工作、会客、餐饮等组不能全部堆在同一角。
   - 不同组之间应有分区，但仍由连续通路连接。

5. **视觉质量与体量平衡**
   - 检查大体量家具是否全部压在同一侧。
   - 允许不对称，但左右/上下总体质量不能严重失衡。

6. **尺度匹配**
   - 房间可容纳更大模数且总分损失在容忍范围内时，优先升级模数。
   - 超大房间不能仍输出紧凑房的小书桌、小餐桌或短柜。

### 四、仍必须是硬约束的内容

- 家具实体不得碰撞、越界或挡门。
- 门扇、柜门和必要操作区不得被硬占用。
- 从入口必须能到达主要家具。
- 最小通过缝隙不得低于项目要求的 0.50m。
- 不允许不可达地面孤岛。

这些不能因为“图片看起来很满”而降级为软扣分。

## 推荐的评分优先顺序

发生冲突时按以下顺序处理：

1. 碰撞、门、0.50m 通路、零孤岛等硬安全规则。
2. 核心功能组完整。
3. 主通路和主要家具可达。
4. 床组、沙发电视组、工作组等关键对象关系。
5. 真实沿墙家具与功能区展开。
6. 模数大小、视觉平衡和空间激活。
7. 可选小件。
8. 填缝收口。
9. 地毯、灯具、床上或桌上陈设。

这能避免“为了填满而破坏使用”“填缝柜比主家具更抢眼”以及“很多小件压过完整功能组”。

## 建议的下一批实现项

## 2026-08-10 已接入的棋谱智能层

- 配置入口：`layoutConstraints.layoutIntelligence`。
- `functionalGroups` 用统一结构声明锚点、成员、目标数量、完整阈值、权重和启用模块；引擎不再为本次新增组团规律写家具专属分支。
- 步骤分：奖励功能组推进和完成，惩罚锚点缺失；粗粒度地面趋势权重也由配置控制。
- 全局分：加入功能组完整度、组间展开度、空间激活和构图质量；总分权重来自 `designQualityRules.weights`。
- 地面分：把家具使用区内的自由空间识别为“有用途留白”，与无功能归属的大洞分开统计；孤岛和 0.50m 通路仍是硬规则。
- 步骤面板：显示“棋谱组团”增量，以及终局的功能、模块、组团、分区展开、空间激活、地墙和通行分解。

仍未完成：把旧 `moduleCompletionMetrics` 和少量历史家具专属启发式彻底迁移到同一配置模型。迁移应继续按规则族逐批进行，不能同时保留两套同义规则。

### P0：直接解决当前显空问题

- 增加“无功能归属的大空地”诊断：空地既不是通路，也不属于任何家具组时扣分。
- 增加“真实墙面占比 / 后补墙面占比”诊断，禁止后补件成为墙面主体。
- 将面积增长明确为：先升级主家具模数，再增加完整功能组。

### P1：让布局更像设计师方案

- 增加功能组质心展开度，避免所有家具堆在一角。
- 增加体量平衡评分，区分合理不对称与严重单边堆积。
- 增加“家具作为软分区边界”的偏好，例如长沙发、长书桌或矮柜分隔两个功能区。

### P2：只用于展示，不进入当前空间评分

- 地毯可用于标注会客/阅读区，但不增加硬家具数量、通行分或地面完成分。
- 床上、桌上、墙上和吊顶物件继续排除在空间棋之外。

## 可用于回归测试的定性问题

每次渲染后至少检查：

- 是否存在完整的核心家具组，而不是孤立小件？
- 大房间是否优先用了更大模数？
- 是否有可用空墙只靠后补件填充？
- 中央空地是主通路/活动面，还是无意义大洞？
- 真实沿墙家具是否形成主次层级？
- 高柜是否遮窗，书桌是否获得合理采光？
- 所有主要家具是否可达，是否仍满足 0.50m 与零孤岛？

## 最终判断

这些图片最值得学习的不是具体坐标，而是三层结构：

1. **外围墙面承担稳定功能。**
2. **中部家具必须形成完整关系组。**
3. **剩余留白必须能被解释为通路或活动面。**

后续调参时，应优先围绕这三层建立配置和评分，而不是继续为单个户型增加坐标特判。
