# 当前 Demo、升级版路由与提速思路

## 1. 当前主页面实现

主页面是目前功能最完整的空间棋 Demo，同时支持卧室、客厅、矩形和正交异形户型。

- 按单件家具逐手生成沿墙、墙角、对象关系和功能区候选；
- 检查多边形越界、家具碰撞、门窗、使用区、通行和零孤岛；
- 用 Beam Search、局部分、前瞻检查和同构去重保留较优棋局；
- 联合评价家具关系、功能组完整度、地面死角/平衡和墙面缝隙/收口；
- 根据面积档选择家具数量与模数，大空间会尝试工作、休闲、客餐等扩展组；
- 输出多套完整方案、逐手棋谱和可折叠的完整搜索树；
- 搜索树支持查看单节点评分明细，以及同一回合最多 4 个节点的分项对比；
- 可读取户型识别 JSON、调整识别房间尺寸，并共享全局家具配置。

## 2. 页面路由与各自效果

| 路由 | 定位 | 当前效果 |
| --- | --- | --- |
| `/` 或 `/bedroom-space-chess-V3.html` | 当前完整 Demo | 卧室和客厅正式演示；支持配置、户型识别、完整单件搜索、方案预览和完整搜索树。 |
| `/furniture-rule-editor.html` | 家具规则配置中心 | 编辑家具模数、数量、落子顺序、候选关系、使用区和全局约束，保存到服务端当前配置。 |
| `/module-growth-prototype.html` | 早期模块生长实验 | 用于观察模块扩展思路，不读取或修改正式主页面配置。 |
| `/bedroom_upgrade/bedroom-space-chess-V3_upgrade.html` | 卧室模块棋升级版 | 先识别卧室局型，再把睡眠、收纳、工作、媒体、休闲和梳妆作为完整模块落子，最后展开成家具验收。支持真实正交多边形、真实门窗、模块锁定和局部重排。 |
| `/bedroom_upgrade/bedroom-golden-regression.html` | 升级版批量回归台 | 展示固定金牌样例的模块完整度、全局分、漏摆机会、搜索节点和耗时，便于判断优化是否退化。 |

两套主棋盘的区别：

- **当前主页面**：能力完整、可覆盖卧室和客厅，优点是细致、规则丰富；代价是单件家具候选组合较多。
- **卧室升级版**：只验证卧室，但一手棋就是一个完整功能模块，关系更稳定、候选更少、解释更直接；当前还没有替代主页面，也暂不支持斜墙。

升级版最新金牌回归为 **7/7 通过**；单例约 **32–164ms**，最复杂样例约 782 个模块节点。该数据用于升级版自身回归，不能与主页面的完整搜索耗时直接等同比较。

## 3. 当前提速思路

### 主页面：在不降低质量的前提下减少重复计算

1. 三套展示方案复用同一轮高质量候选池，不重复执行三遍完整搜索。
2. 候选先按配置、关系和墙段质量排序，只让强候选进入昂贵碰撞与通行检查。
3. 使用 Bitset/批量矩阵完成碰撞初筛；Beam 中途采用粗网格引导，最终方案仍用完整精度验收。
4. 先预截断，再做前向检查和通行检查；弱分支不分配完整占用数据。
5. 用状态哈希、家具类型代表分支和数量代表分支去重，同时保留少量差异化棋局。
6. 搜索树保留数据但默认折叠，避免一次绘制上万个节点拖慢页面。

当前正式基准记录：质量样例 **12/12 通过**，p95 约由 **2.9s 降至 0.47s**；压力样例 **22/22 通过**，总耗时约由 **20s 降至 5.3s**。

### 升级版：从搜索结构上减少组合爆炸

1. 先按面积、长宽比和拓扑匹配少量棋谱，最多让两条接近的棋谱进入决赛。
2. 一手生成完整功能模块，模块内部先闭合床—床头柜、桌—椅、媒体—观看目标等关系。
3. 候选只落在墙端、墙中、门窗边界和模块对齐点等语义临界位置，不做全房间均匀扫描。
4. Beam 固定为 16，并保留不同“功能—墙段—位置”代表，避免同质高分分支占满 Beam。
5. 主棋结束后才做床头柜补全、定制柜残局和漏摆机会反事实检查。
6. 用户锁定模块后只重排未锁定部分，为后续局部搜索和增量缓存留出接口。
7. 多棋谱竞赛设总预算；当前卧室目标为 240ms 内完成模块搜索和组合决赛。

## 4. 下一步建议

- 保持主页面作为功能基线，升级版继续作为新搜索架构的质量与速度试验场；
- 先用卧室金牌样例稳定棋谱、模块关系和精确通行，再逐步迁移到正式主页面；
- 客厅升级时复用相同框架，将模块替换为会客组、视听组、餐组和收纳组；
- 每次提速同时记录质量通过率、p95、节点数、候选数和漏摆机会，不能只比较运行时间；
- 暂不因性能原因把浏览器引擎改成 Python：当前主要瓶颈是候选数量和重复搜索，跨端通信反而会增加成本。

## 5. 启动

```bash
uv sync --frozen
uv run --frozen room-chess-server
```

服务默认监听 `0.0.0.0:8765`，本机可通过 `http://127.0.0.1:8765/` 访问。
